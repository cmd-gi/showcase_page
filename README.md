# Charan's Creative Portfolio

A premium, highly interactive digital portfolio built to showcase the intersection of machine intelligence and human creativity. This portfolio features a dark, cinematic aesthetic designed to display AI art, cinematic video editing, and modern web development projects.

## ✨ Features

- **Generative 3D Hero:** A fully custom WebGL (Three.js) interactive sphere that uses Perlin noise to warp and morph in real-time, matching the brand's primary orange theme.
- **Masonry Poster Grid:** A responsive, masonry-style image gallery for displaying high-resolution artwork and posters without harsh cropping.
- **Custom Video Engine:** A dynamic video grid featuring auto-pausing logic (playing one video automatically pauses the others), buffering animations, and custom generated poster thumbnails.
- **Live Web Previews:** Interactive `iframe` showcases that allow visitors to browse live Next.js and React deployments directly from within the portfolio cards.
- **Premium Animations:** Extensive use of `framer-motion` for smooth scroll reveals, hover effects, and layout transitions.

## 🛠️ Tech Stack

- **Framework:** React 19 + Vite
- **Styling:** Tailwind CSS 4
- **Animations:** Framer Motion
- **3D Graphics:** Three.js
- **Icons:** Lucide React & React Icons
- **Package Manager:** pnpm

## 🚀 Getting Started

To run this project locally:

1. **Install Dependencies**
   Ensure you have [pnpm](https://pnpm.io/) installed, then run:
   ```bash
   pnpm install
   ```

2. **Start the Development Server**
   ```bash
   pnpm run dev
   ```

3. **Build for Production**
   ```bash
   pnpm run build
   ```

## 🌐 Deployment

This project is fully optimized for immediate deployment on [Vercel](https://vercel.com). Simply link your GitHub repository to Vercel, and it will automatically detect the Vite build settings.
